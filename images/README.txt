THE BONEVERSE — IMAGE FOLDER

Put your movie and YouTube video thumbnail images in this folder.

Recommended format: JPG, PNG or WEBP.
Recommended thumbnail shape: 16:9.

Example filenames:
  the-test.jpg
  facility-01.webp
  bone-run.png

To connect an image to a film, add its path to that film's image field in the MOVIES list in the root index.html:
  image: "images/the-test.jpg"

The same image is used as the film poster and the thumbnail in the film gallery.

Adding an image file alone does not create a movie card. The film's title, release date, duration and YouTube URL are added in the MOVIES list in index.html.
